# 01.オリエンテーション

## 授業の概要
- 本講義は、臨床工学科の大学4年生を対象に、来年の国家試験に向けた医用画像装置と画像処理技術の基礎から応用までを学習することを目的としています。
- 可能な限り、画像処理に関連する国家試験範囲は復習しつつ、応用的な内容も多少含め、「暗記」ではなく「理解」に繋がるよう構成していければと思います。

## 到達目標
- **基礎知識の定着:** 国家試験に必要な医用画像装置・画像処理技術の基礎理論を復習する。
- **応用力の向上:** 従来の範囲に加え、最新技術動向や実践例を通じて、臨床現場での判断力と問題解決力を身につける。
- **試験対策の完了:** 演習問題を通じ、国家試験対策に必要な知識とスキルを確実に習得する。

## シラバスと国家試験出題基準との対応表
- 令和8年度の国家試験出題基準では、専門基礎科目（医学概論、医用電気電子工学、医用機械工学、生体物性材料工学）と専門科目（生体機能代行装置学、医用治療機器学、生体計測装置学、医用機器安全管理学、臨床医学総論）に分け、各分野の知識・技能が評価されます。

## 本講義で学ぶ内容と国家試験の位置づけ
医用画像装置と画像処理技術は、現代医療の重要な技術基盤です。令和8年度の国家試験出題基準では、各専門基礎科目および専門科目に沿って以下のような観点が評価されます。

- **専門基礎科目:**  
    - **医学概論:** 臨床工学に必要な医学的基礎、人体の構造・機能  
    - **医用電気電子工学:** 情報処理工学を含む、数値表現、量子化、A/D変換、サンプリングなど  
    - **医用機械工学:** 医用機器の構造や動作原理  
    - **生体物性材料工学:** 生体材料の特性とその応用

- **専門科目:**  
    - **生体機能代行装置学:** 呼吸療法装置、体外循環装置、血液浄化療法装置など  
    - **医用治療機器学:** 電気的治療機器、手術支援システムなど  
    - **生体計測装置学:** 医用画像計測、超音波、MRI、核医学画像などの計測技術  
    - **医用機器安全管理学:** 医用機器の安全管理やリスクマネジメント  
    - **臨床医学総論:** 内科学、外科学、呼吸器系、循環器系など、臨床現場での総合的知識
